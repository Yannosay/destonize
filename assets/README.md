# Asset Requirements

Place the following assets in the `assets` folder:

- `app-icon.ico` – Application icon (ICO format, 256x256).
- `logo.png` – Logo used in about dialog (PNG, 512x512).
- `splash-screen.png` – Optional splash screen (PNG, 800x600).

If these files are missing, the application will still build but will not have custom icons.
